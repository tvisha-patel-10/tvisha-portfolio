# Tvisha Patel's Portfolio

Welcome to my corner of the internet! This is the code behind my portfolio, where I share my product design work and a few playful experiments.

🔗 **Live site:** [tvishapatel.com](https://tvishapatel.com)

## What's inside

- **Case studies:** Strawberry.me, BetterHelp, and EchoKids, from first idea to final screen
- **A design system page:** the colors, type, spacing, and little details behind this site
- **A Playground:** small interactive projects like [Hue Hunt](https://github.com/tvisha-patel-10/hue-hunt), [Badgecraft](https://github.com/tvisha-patel-10/badge-craft), and [Piano Pal](https://github.com/tvisha-patel-10/piano-pal)

## Design details

Read more about my site's design system [here](https://tvishapatel.com/design-system/)
- Warm cream and terracotta palette with accessible color contrast
- Three fonts, three jobs: Geom for headlines, Figtree for body text, and Gloria Hallelujah for handwritten accents
- A custom cursor that morphs depending on what you hover
- A fluid type scale and a 4/8px spacing system

## Tech stack

- Astro
- TypeScript
- HTML / CSS
- Deployed via GitHub and Cloudflare
